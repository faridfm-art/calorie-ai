# Calorie AI - Google Gemini

1. Install Node.js LTS.
2. Buka folder ini di VS Code.
3. Copy `.env.example` menjadi `.env`.
4. Isi `GEMINI_API_KEY` dengan API key baru dari Google AI Studio.
5. Jalankan `npm.cmd install` jika PowerShell memblokir npm.ps1.
6. Jalankan `npm.cmd start`.
7. Buka http://localhost:3000

Jangan masukkan API key ke index.html. Jangan membagikan `.env`.
